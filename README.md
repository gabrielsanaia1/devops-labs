## Lab 01 — სცენარი

Spring Boot ვებ-აპლიკაციაში ემატება სტუდენტების სახელით ძებნის ფუნქცია (`GET /students?name=...`). ერთი შემსრულებელი თანმიმდევრობით ასრულებს ყველა როლს: ანალიტიკოსი, დეველოპერი, ტესტერი, release/deploy პასუხისმგებელი და ოპერაციების მონიტორინგი.

**შენიშვნა:** VSM-ში დროები სასწავლო სიმულაციის შეფასებებია; ჩამოთვლილი ინსტრუმენტები აღნიშნავს სცენარში გამოსაყენებელ ინსტრუმენტებს და არა იმას, რომ CI/CD ან მონიტორინგი უკვე გამართულია.
